## 📊 Análisis y Minería de Datos

---

En este cuaderno se realizó un proceso integral de análisis y modelado de datos que incluye los siguientes componentes clave:

* **Gráficas a partir de consultas SQL:** Generación de visualizaciones directamente desde la extracción de datos mediante consultas SQL.

* **Minería Descriptiva:**
    * **Clustering con K-Means:** Aplicación del algoritmo K-Means para la segmentación de datos.
    * **Perfilamiento:** Caracterización detallada de cada cluster resultante.

* **Minería Predictiva:**
    * Evaluación de **varios métodos** de modelado.
    * Optimización de modelos mediante **hiper-parametrización**.
    * **Modelo con mejores resultados:** Un **Random Forest con 500 árboles**.
    * **Despliegue:** Implementación del modelo para predicción, incluyendo pruebas con **3 datos de ejemplo**.

* **Dashboard:** Creación de un **dashboard interactivo** para la visualización final de todos los resultados obtenidos.

---

### 🏆 Modelo Destacado

El método con mejores resultados fue un **Random Forest con 500 árboles**.
